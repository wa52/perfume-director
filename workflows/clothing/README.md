# 男装 / 女装四方向闭环

主入口是 `menswear.ui.json`、`womenswear.ui.json`。其余 16 个文件预先选好细分品类；它们不是固定构图或风格模板。

1. 在部署了本项目节点的 ComfyUI 导入工作流。
2. 把示例图替换成对应服装的透明 PNG，连接同一 LoadImage 的 IMAGE 和 MASK。
3. 选择商品分类、garment_type、display_mode，填写实际文案或使用默认简报，点击运行。
4. 节点显示四个新方向的生成进度、草稿、最终图和评审状态。COMPLETED 只表示运行结束；NEEDS_REVIEW 仍需修改或人工验收。

男装细分：衬衫、T恤、针织、西装、外套、裤装、运动服。女装另有连衣裙、半裙。两者都是明确的商品分类，系统不据人物外观推断性别。

展示方式说明：

| display_mode | 输入要求 |
| --- | --- |
| auto | 保留原透明图呈现，不自动穿衣或转换视角 |
| flat_lay | 已拍摄的平铺服装 |
| hanging | 已拍摄的悬挂服装 |
| ghost_mannequin | 已拍摄并抠好的立体人台服装 |
| original_model | 已授权、抠好的原图模特及完整服装，整体合成 |

这些选项描述输入照片，不会把平铺服装变成悬挂、重新造人或实现虚拟试衣。非原图模特模式保持图形/材质场景，并禁用瓶底式地面阴影。Critic 分别检查领口、门襟、袖长、针织纹理、裤长、裙摆和实际图案。

参考按男装/女装独立检索。细分品类不足三个品牌时，显式记录 `same_audience_style_fallback`，使用同一男装/女装类别的设计语言，不调用香水或另一服装类别凑数。参考原作品版权保留；测试用 T恤和裙装来自 PNGimg，CC BY-NC 4.0，仅供非商业测试。商业交付须换成自己的商品素材。
