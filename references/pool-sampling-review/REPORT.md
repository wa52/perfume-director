# 参考库扩大后仍重复：参考选择回归

对同一100图数据库，分别使用修改前与修改后参考选择器，固定随机种子0～19，每次取8张。

| 指标 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 160个位置实际覆盖的图像 | 15 | 59 |
| 覆盖的独立广告排版参考 | 3 | 16 |
| 单张最高入选次数 | 20 | 9 |
| 每组至少两张广告排版参考 | 是 | 是 |

旧逻辑只在最高评分相同时随机，扩大库后仍反复选择少数作品。新逻辑在当前最佳综合分12分以内做加权抽样，并对最近8个规划池重复出现的图像扣分，最高扣18分。仍保留质量、渲染适配、品牌差异、设计特征和来源分散要求。

这只是离线选择器验证，不证明生成海报的审美或随机性已经达标。完整抽样ID、历史使用计数、前后代码哈希见 [comparison.json](comparison.json)。已启动的批次使用其启动时的旧选择器；后续新进程才使用这一修复。
