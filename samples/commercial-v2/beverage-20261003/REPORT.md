# Commercial V2 beverage pilot — 2026-10-03

This evidence records real Qwen planning, not a finished advertisement or a successful commercial run.

- The initial two-stage plan returned four mostly neutral packshot compositions. It passed structural layout checks but was rejected as creative repetition. `InitialConcepts-rejected.json` preserves that failure.
- The new independent semantic reviewer rejected two successive batches: floor-treatment variants first, then two equivalent decorative-backdrop graphics. `CreativeReview-1.json` and `CreativeReview-2.json` contain its actual evidence and required revisions.
- The third revision received a model semantic approval (`CreativeReview-3.json`, `CreativeGate.json`). Proposed mechanisms: enlarged contour projection, script-derived rings, a hospitality tabletop relationship, and a ground-plane contour trace. Semantic approval is not a renderer feasibility approval: wall projection and raised/table surfaces remain unsupported by the current physical compositor. Do not claim these concepts have been implemented merely because a model approved the prose.
- A preliminary render submission against legacy port 8190 failed HTTP 400: four required background node types were absent. The pilot now defaults to project service 8191 and checks configured node types before submission. No poster from this failed render exists.
- Art Director/layout validation completed for four directions (`ArtPlans.json`). Actual ComfyUI backgrounds and the local V2 compositor were tested for a graphic direction and a photographic direction. Original source RGB remains preserved.
- Graphic V1 scored 75.4. Its ripple ellipses incorrectly used the desired center as upper-left coordinates; the Critic supplied that root cause and corrected the shape list. V2 scored 90.6 and passed the initial numeric/check gate. Direct visual inspection still found a generic target motif and weak brand typography. A separate final Art Director, without the first scores, classified V2 as **draft**, citing an invisible wordmark-echo concept, generic serif brand text, weak alignment and jagged source edges. `graphic/v2/ReleaseDecision.json` is NEEDS_REVIEW; the original numeric approval is retained rather than rewritten. This disagreement led to an independent final-review stage in the engine. No commercial acceptance is claimed.
- Photographic direction completed four rendered/reviewed versions: 78.9, 78.6, 81.1, 85.4. V1 failed grounding: the drape looked like a vertical table skirt, with no readable horizontal surface under the bottle. A contact shadow alone did not solve the plane mismatch. V4 no longer triggered the grounding veto, but typography, composition and creative coherence remained below gate thresholds. V4 was selected with status NEEDS_REVIEW (`photographic/result.json`), not commercial PASS. Two proposed directions remain unrendered; this is not a completed four-direction V2 batch.

172 tests passed. They include original-product preservation in the external-shadow routine, direction of frontal-light projection, unknown-source-light rejection, immutable source-light patches, missing-evidence vetoes, geometric vetoes, semantic repair before layout, final-review rejection of high-scoring generic work, and an unavailable final-review veto. Tests do not establish aesthetic quality.

The V2 gate uses fidelity >=95, physical integration/typography/composition/creative coherence >=88 and brand alignment >=85, plus explicit evidence for all veto checks. Original RGB and alpha are retained; cast/contact shadows are 2D approximations. There is no true material-zone relighting, glass-transmission reconstruction, depth estimation or reconstructed reflection.

The 20-run acceptance target remains untested. Legacy gallery images and existing legacy PASS results are not V2 approvals.
