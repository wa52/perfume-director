# 可精确修改的背景图形：真实两轮验证

原先圆形等图案依赖背景模型根据文字生成，Critic 即使要求平移，也无法保证实际移动。本次把圆形写进 `background.shapes`，由确定性合成器按坐标、尺寸、颜色、透明度绘制；背景模型负责纸面材质。

初版迁移由 Codex 根据已有方案完成，因此不是独立 Director 从零规划的案例。之后千问 Critic 看真实成品，把圆形从 `(80,650,600,600)` 改为 `(150,640,640,640)`，同时修改纸面、字距和文字位置。ComfyUI 实际执行了第二版；规格与 Critic 命令完全匹配，像素检查也验证了可见圆形的左边界。

模型评分 78.3 → 80.6，两版均为 **NEEDS_REVIEW**，选中 V2。评分变化不代表人工审美通过。当前文字节奏和商品融入仍不足，图形可控只解决“修改命令能否准确执行”。
